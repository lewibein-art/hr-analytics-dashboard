# HR Analytics Dashboard: Анализ выгорания и текучести персонала

 **Инструмент:** Apache Superset  
 **Данные:** Kaggle (Employee Burnout & Productivity Dataset)  

## 🎯 Бизнес-задача
Выявить факторы, влияющие на выгорание сотрудников и текучесть кадров, 
оценить влияние режима работы и поддержки руководства на производительность.

## 🔑 Ключевые инсайты
- **Текучесть кадров:** 17.9% — критический уровень, требующий вмешательства
- **Гибридный формат** показывает наименьшую текучесть (376 уволившихся vs 1861 работающих)
- **Поддержка руководства** имеет обратную корреляцию с выгоранием: 
  при оценке поддержки 8-10 уровень выгорания стабилизируется на 3-4 балла
- **ИИ в работе:** 73% сотрудников используют ИИ-инструменты, что влияет на производительность

## 📈 Метрики на дашборде
- Общая численность: 5,000 сотрудников
- Средний возраст: 37.1 лет
- Средняя зарплата: 62,920 руб.
- Средний уровень выгорания: 4.03/10
- Оценка поддержки руководства: 6.61/10

## 💡 Рекомендации для HR-департамента
1. Внедрить программы ментальной поддержки для сотрудников с низким уровнем 
   оценки поддержки руководства (<4 баллов)
2. Расширить гибридный формат работы — он показывает наилучшее удержание
3. Провести обучение руководителей навыкам поддержки команды
4. Исследовать влияние ИИ-инструментов на выгорание (возможно, цифровая 
   трансформация требует дополнительных ресурсов)
